Camadas de proteção

🔐

Cofre criptográfico

AES-256-GCM + PBKDF2 (210k). A nota do dono é cifrada; nada em texto puro.

🧱

Chaves no hardware

Selo por chave não exportável do Android Keystore. Extrair o arquivo não quebra o PIN offline.

🚨

Resposta anti-roubo

3 PIN errados → wipe do cofre + lockNow + factory reset (Device Admin oficial).

🔓

Liberação e recuperação

Libere com o PIN e desative a proteção. Código de recuperação offline para reativar.

Como funciona

  1. Instale o APK e abra o JP Secure Lock.
  2. Permita exibir sobre outros apps e ative o Administrador do dispositivo.
  3. Defina o app como HOME para o botão Início voltar ao bloqueador.
  4. Crie um PIN forte (6+ dígitos) e guarde o código de recuperação offline.
  5. Em tentativa de roubo: 3 erros apagam todos os dados do aparelho.
  6. Após uso legítimo: desbloqueie e libere/desative a proteção.

Segurança, com honestidade

Nenhum software é "impossível de hackear". Veja exatamente o que este protege — e os limites conhecidos.

CenárioRealidade
Ladrão comum sem o PINAparelho inutilizável; dados apagados após 3 erros
Extração do arquivo em aparelho com rootSem ataque offline: chave presa ao hardware
Zerar o contador editando o arquivoBloqueado: armazenamento cifrado e autenticado
Reflash por fastboot/recoveryPode apagar o aparelho — mas não recupera os dados cifrados
"Queimar" RAM / destruir hardwareImpossível e não é objetivo do projeto

Atenção: no modo máximo, 3 PIN errados apagam fotos, apps e contas. Faça backup. Use apenas no seu aparelho ou com consentimento explícito do dono.
