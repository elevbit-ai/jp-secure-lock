Android · Anti-Theft · Hardware-sealed crypto

Your Android, useless in the wrong hands

JP Secure Lock protects the device with a PIN, AES-256-GCM encryption whose keys never leave the secure hardware, and an anti-theft response: after 3 wrong passwords it wipes the vault and runs the official Android factory reset.

How it works

  1. Install the APK and open JP Secure Lock.
  2. Allow drawing over other apps and enable Device Administrator.
  3. Set the app as HOME so the Home button returns to the blocker.
  4. Create a strong PIN (6+ digits) and store the recovery code offline.
  5. On a theft attempt: 3 failures erase all device data.
  6. After legitimate use: unlock and release/deactivate protection.

Security, honestly

No software is "impossible to hack". Here is what this protects — and the known limits.

ScenarioReality
Common thief without the PINDevice unusable; data erased after 3 failures
File extraction on a rooted deviceNo offline attack: key bound to hardware
Reset the counter by editing the fileBlocked: encrypted, authenticated storage
Reflash via fastboot/recoveryMay erase the device — but cannot recover encrypted data
"Burn" RAM / destroy hardwareImpossible and not a project goal

Warning: in maximum mode, 3 wrong PINs erase photos, apps, and accounts. Back up first. Use only on your own device or with the owner’s explicit consent.
